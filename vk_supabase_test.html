VK ID × Supabase

Тестовая авторизация

Проверка входа через VK ID и соединения с Supabase. Страница работает как один HTML-файл, без собственного сервера.

Готово к настройке. Заполните APP_ID и Redirect URL.

Пользователь VK

Важно: VK ID и Supabase Auth — два разных этапа. Этот прототип запускает VK ID OAuth и показывает результат профиля, а также проверяет доступность Supabase. Он не создаёт Supabase Auth-сессию автоматически: для этого нужен серверный обмен/проверка личности (например, Supabase Edge Function с безопасной серверной логикой). Не вставляйте сюда service_role key или VK client secret.

Локальный тестовый интерфейс · ключи не сохраняются в localStorage
